# Jarvis Mail Development Roadmap

## Project Goal

Build an AI-powered email assistant that helps users manage their inbox by automatically classifying, summarizing, and prioritizing emails.

---

# Phase 1 - Foundation ✅

Completed

- Project architecture
- FastAPI backend
- Database models
- AI email classification
- Gmail/Outlook integration
- Secure authentication (Supabase)
- API endpoints
- Testing
- GitHub repository

Status:
Completed

---

# Phase 2 - User Experience

Current Phase

Objectives:

- Build dashboard UI
- Connect user Gmail account
- Display AI classified emails
- Morning Brief
- Search functionality
- OTP / Verification Code section
- Business Lead dashboard
- Notification center

Goal:

A user should be able to sign in, connect Gmail, and understand their inbox within 30 seconds.

---

# Phase 3 - Internal Testing

Objectives:

- Use Jarvis Mail personally
- Test multiple email categories
- Test business leads
- Test OTP detection
- Find UI bugs
- Improve AI summaries
- Improve dashboard usability

Goal:

Use Jarvis Mail daily until it feels reliable.

---

# Phase 4 - Beta Testing

Objectives:

- Invite a small number of users
- Collect feedback
- Fix reported bugs
- Improve performance
- Reduce AI costs

Goal:

Validate the product with real users.

---

# Phase 5 - Public Launch

Objectives:

- Build marketing website
- Subscription plans
- Stripe payments
- Public signup
- Launch

Goal:

Acquire paying customers.

Future ideas:

---

# Product Philosophy

Every feature should answer one question:

"Does this save the user time or reduce mental effort?"

If the answer is no, it belongs in the backlog instead of the product.
