# Jarvis Mail Dashboard

## Goal

The dashboard should allow a user to understand everything important in their inbox within 30 seconds.

---

# Home Screen

The first screen should immediately show:

- 🔥 Business Leads
- 📅 Meetings
- 💰 Invoices
- 🔐 Verification Codes (OTP)
- ⚠️ Security Alerts
- 📦 Orders & Deliveries
- 📰 Newsletters
- 📢 Promotions

It should also display:

- Total unread emails
- High priority emails
- Estimated reading time
- AI Morning Brief

---

# AI Morning Brief

The AI should generate a simple daily summary including:

- Important emails
- New business leads
- Meetings
- Invoices
- Security alerts
- Suggested actions

---

# Email List

Each email should display:

- Sender
- Subject
- Category
- Priority
- AI Summary
- Suggested Action
- Time Received

---

# Business Leads

Each business lead should display:

- Company Name
- Contact Name
- Email
- Phone (if available)
- AI Summary
- Suggested Next Step
- Approve
- Reject

---

# Verification Codes (OTP)

Create a dedicated section for authentication emails.

Display:

- Service Name
- Verification Code
- Expiration Time (if available)

---

# Search

Allow searching by:

- Sender
- Subject
- Company
- Category
- Keyword

---

# Dashboard Design Philosophy

The dashboard should be clean and modern.

A user should immediately know:

- What is urgent
- What needs action
- What can be ignored

The goal is to reduce inbox stress and save time.
